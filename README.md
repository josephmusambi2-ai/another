# 📚 Books & Learning — Greenfield Academy

A school website about how reading books helps students succeed academically and personally.

## About

This site was built as a learning project to practise using GitHub. It covers:
- Why books matter for students
- Key benefits of reading (memory, writing, critical thinking, empathy, focus)
- Tips to build a daily reading habit
- A recommended book list curated for students

## Pages

| File | Purpose |
|------|---------|
| `index.html` | Main (and only) page — all sections |
| `style.css` | All styling and layout |
| `script.js` | Scroll animations and stat counters |

## How to View Locally

1. Download or clone this repository
2. Open `index.html` in any web browser — no server needed

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPO-NAME.git
cd YOUR-REPO-NAME
open index.html   # Mac
# or just double-click index.html in your file explorer
```

## How to Deploy on GitHub Pages (Free Hosting)

1. Push this code to a GitHub repository
2. Go to **Settings → Pages**
3. Under *Source*, select **Deploy from a branch**
4. Choose **main** branch and **/ (root)** folder
5. Click **Save** — your site will be live at `https://YOUR-USERNAME.github.io/YOUR-REPO-NAME`

## Technologies Used

- HTML5
- CSS3 (CSS variables, Grid, Flexbox, animations)
- Vanilla JavaScript (Intersection Observer API)
- Google Fonts (Playfair Display + DM Sans)
